# Contributing

As this is a community project, any kind of feedback, contribution, help, etc. is welcome.
It is all publicly available on github [here](https://github.com/PerformancePortablePatterns/performanceportablepatterns.github.io) (or in the top right corner). Please feel free to create pull requests if there is anything you think should be changed/added/removed.
Also notice, that every page has a "view source" and "edit" button in the upper right section that allows to propose edits quickly and conveniently.

## Adding a pattern
Please also feel free to create pull-requests or issues on github if you want to add a pattern. I will do my best helping to get it on the website.
Alternatively, you can use my github handle @JBludau anywhere on github you want me to look. 
There is no established process yet (and maybe never will), this will be made up along the ride.

## Code of Conduct

In the interest of fostering an open and welcoming environment, we all pledge to making participation in the project and community a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.
We are respectful and show empathy towards each other at all times.
